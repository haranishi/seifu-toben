# 政府はこう答えてきた

国会会議録から**政府側の答弁だけ**を抜き出し、テーマごとに「いつ・どの省庁が・何と答えてきたか」を年表にする。
出典：[国会会議録検索システム](https://kokkai.ndl.go.jp/)（国立国会図書館）。認証不要・CORS許可済み。

```bash
npm test                      # ロジックのテスト（15件）
python3 -m http.server 8788   # 素の静的ファイルなのでビルド不要
```

## なぜ政府答弁に限るのか

元の着想は「議員の人物像と、過去の発言の矛盾をまとめる」だった。**法務リスクが企画の中核を直撃するため、政府答弁に限定した。**

- **著作権法40条1項**は政治上の演説の自由利用を認めるが「**同一の著作者のものを編集して利用する場合を除き**」とある。一人の議員の発言を集める設計は、この除外に真正面から当たる
- 「この議員は矛盾している」という表示は**名誉毀損**になりうる。免責には真実性が要るが、AIの矛盾判定は誤る。立場の変化は矛盾ではないし、質問者と答弁者では発言の役割がそもそも違う
- 選挙期間中に特定候補の評価を出すと**公職選挙法**の論点が乗る

政府答弁は国の公式見解なので、個人の評価にならず、時系列に並べると方針の変化が見え、引用価値も最も高い。

## 設計判断

- **全文を持たない。** 表示は抜粋のみで、原文はNDLの`speechURL`へリンクする。著作権と、一次情報を本家で読ませる方針の両方に効く
- **断定しない。** 矛盾の自動判定は実装しない。時系列に並べれば読んだ人が自分で気づく。価値は落ちず、法務リスクだけが消える
- **取得上限2000件。** NDLが「短時間の大量アクセスはご遠慮ください」と明記している。超過時は取得せず絞り込みを促す（「予算」は78万件あり、無防備だと7,800回叩く）

## 落とし穴（実測で判明したもの）

- **`speakerPosition`の有無だけで政府を判定してはいけない。** 民間の参考人にも肩書が入る（「株式会社◯◯上席研究員」「日本放送協会理事」「公益財団法人◯◯保護室室長」）。府省庁名＋政府役職のホワイトリストで判定している
- **「環境副大臣」は「環境大臣」を含まない。** 素朴な文字列一致だと全省庁の副大臣・政務官が所管不明に落ちる。`lib/gov.js`の`MINISTER_PATTERNS`はこのために正規表現になっている
- **`speakerGroup`は会派であって政党ではない。** 「自由民主党・無所属の会」のように無所属を含む。政党と書くと誤情報になる
- **会議録の公開は審議から3〜4週間遅れる**（速記録のため）。「今日の答弁」は原理的に作れない
- **バーの`<span>`に`display:block`を付け忘れると幅指定が無視される。** 全省庁が同じ長さに見え、「どこも同じだけ答弁している」と誤読させる状態になっていた

## やらないと決めたこと

- 矛盾の自動判定（上記の理由）
- 議員個人の人物像・発言集
- 答弁の全文保持

## 公開前に人間がやること

- `index.html`の`canonical` / `og:url` / `og:image` が `https://example.invalid/` のまま。公開先が決まったら実URLに差し替える
- OGP画像（`ogp.png`）を用意する
- 法務の確認。特に選挙が近い時期に公開する場合
